# Curriculum

Classroom alignment lives in [PRD section 29](../PRD.md#29-classroom-use-and-curriculum-alignment).

The same public artifact can support different depths:

- Grade 9: play, write rooms, report bugs, critique interfaces
- Introductory courses: IPO, variables, tests, command help
- Intermediate courses: modules, data structures, files, client scripts
- Server-side and project courses: persistence, validation, planning, review

Curriculum mapping is based on the Alberta Education Computing Science Program of Studies, including CSE1010, CSE1110, CSE1120, CSE1210, CSE1910, CSE2010, CSE2110, CSE2120, CSE2130, CSE2210, CSE3120, and CSE3210.

Add lesson notes here as they are written. Do not store student work, marks, or personal information in this folder.
