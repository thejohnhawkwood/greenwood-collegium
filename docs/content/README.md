Author truth for the Greenwood Collegium. Runtime truth remains JSON under
`packages/content/`. If a bible and a live file disagree, students play the live
file until a content ticket lands.

| File | Owns |
| --- | --- |
| [STORY.md](STORY.md) | Tone, cast, **quest spine**, open mysteries |
| [quests/](quests/README.md) | One markdown file per storyline |
| [PROGRESSION.md](PROGRESSION.md) | Field Primer, ranks, every leaf |
| [adventures.md](adventures.md) | How to play and how to author JSON |
| [room-and-quest-summary.md](room-and-quest-summary.md) | Live room IDs, exits, objective inventories |
