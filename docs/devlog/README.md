# Devlog

Public chronological notes for humans, students, and agents. Write an entry when a ticket lands, a session ends, or a machine handoff is needed.

Do not record secrets, connection strings, student names, or production logs.

## Template

```markdown
# YYYY-MM-DD — short title

## Intent
What was this session trying to finish?

## Machine
Desktop, work laptop, CI, or Render.

## What changed
Files, tickets, and behaviour. Keep it short.

## PRD / ADR
Links to the law you followed.

## Classroom note
What a student can inspect or explain.

## Next
The single next ticket or human step.

## Open questions
Unresolved risks. Do not hide confusion.
```
